# Biosol Workspace Setup (Plans, Tasks, Rules & Skills)

## Contents
- `PLAN.md` — Complete product architecture, UI specs, formulas, connection rules, and API contracts.
- `TASKS.md` — 6-phase step-by-step execution checklist for Zoo Code.
- `.roo/rules/01-biosol-workflow.md` — Always-active phase isolation & checklist rules.
- `.roo/rules/02-biosol-architecture.md` — Always-active FastAPI, Pandas, and React/TypeScript coding standards.
- `.roo/skills/biosol-bioinformatics-engine/SKILL.md` — On-demand skill for Python genetic analysis & Plotly blocks.
- `.roo/skills/biosol-canvas-workflow/SKILL.md` — On-demand skill for React Flow canvas, Scratch blocks & port validation.
- `.roo/skills/biosol-ai-assistant/SKILL.md` — On-demand skill for Llama 3.3 70B & `SYSTEM_PROMPT.md`.

## Installation
1. Extract this ZIP directly into the root folder of your `biosol-mvp` repository (make sure hidden folders like `.roo` are extracted).
2. In Zoo Code, click the refresh icon or reopen the workspace—your **Workspace Rules** (2 files) and **Workspace Skills** (3 skills) will appear automatically in Zoo Code Settings.
3. Run each phase in a separate Zoo Code task:
   - `Read PLAN.md and TASKS.md, then complete Phase 1 only.`
   - `Read PLAN.md and TASKS.md, then complete Phase 2 only.`
   - `Read PLAN.md and TASKS.md, then complete Phase 3 only.`
   - `Read PLAN.md and TASKS.md, then complete Phase 4 only.`
   - `Read PLAN.md and TASKS.md, then complete Phase 5 only.`
   - `Read PLAN.md and TASKS.md, then complete Phase 6 only.`
